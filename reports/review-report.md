# Rapport Code Review

_Non publié dans le repo démo public._

`reports/local/review-report.md`, qui est ignoré par git. Il n'est pas publié
ici parce qu'il nomme des fichiers et des numéros de ligne, sur une démo
accessible en ligne. Ce fichier-ci reste volontairement vide de tout finding.
