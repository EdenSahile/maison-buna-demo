# Rapport Tests

_Non publié dans le repo démo public._

`reports/local/test-report.md`, qui est ignoré par git. Il n'est pas publié ici
parce qu'il liste les bugs détectés avec leurs fichiers et leurs numéros de
ligne, sur une démo accessible en ligne. Ce fichier-ci reste volontairement
vide de tout finding.
